# 🔄 Reverse Number

A simple Python program that reverses the digits of a given integer using basic mathematical operations and a `while` loop.

## 📌 Description

The program takes a number from the user and reverses its digits.

### Example

```text
Input: 12345
Output: 54321
```

## 🧠 Logic Used

The program uses:

* `% 10` to extract the last digit.
* `// 10` to remove the last digit.
* A `while` loop to process every digit.
* `reverse * 10 + digit` to build the reversed number.

## 💻 Concepts Practiced

* User input
* Type conversion
* `while` loops
* Modulo operator `%`
* Floor division `//`
* Variables
* Basic problem-solving and logic building
