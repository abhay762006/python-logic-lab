# Prime Number Checker

A simple Python program that checks whether a given number is a **prime number** or not.

## 🧠 What is a Prime Number?

A prime number is a number greater than 1 that has exactly **two factors: 1 and itself**.

Examples:

* 2 → Prime
* 3 → Prime
* 5 → Prime
* 7 → Prime
* 9 → Not Prime

## 🚀 How It Works

The program takes a number as input and checks whether it can be divided evenly by any number other than 1 and itself.

## 🛠️ Technologies Used

* Python

## ▶️ How to Run

```bash
python prime.py
```

Enter a number when prompted, and the program will tell you whether it is prime or not.

## 📌 Example

```text
Enter the number: 17
17 is a prime number
```
