# 🔢 Even or Odd

A simple Python program that determines whether a given number is **even or odd**.

## 🧠 Concepts Used

* User Input
* Variables
* Conditional Statements
* Modulus Operator `%`

## ⚙️ How It Works

A number is:

* **Even** if it is completely divisible by `2`
* **Odd** if it leaves a remainder when divided by `2`

The program uses the modulus operator:

```python
number % 2
```

If the result is `0`, the number is even; otherwise, it is odd.

## 💻 Example

```text
Enter a number: 7

Output:
7 is Odd
```

Another example:

```text
Enter a number: 12

Output:
12 is Even
```

## 🎯 Goal

This problem is designed to practice basic **conditional logic** and understand how the modulus operator can be used to solve programming problems.
